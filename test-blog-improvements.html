Debounce en Búsqueda IMPLEMENTADO

Eliminación de búsquedas innecesarias durante la escritura

// Búsqueda solo se ejecuta después de 300ms de inactividad const debouncedValue = useDebounce(searchQuery, 300); useEffect(() => { if (debouncedValue !== searchQuery) { onSearch(debouncedValue); } }, [debouncedValue, onSearch]);
